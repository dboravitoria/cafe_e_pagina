# ☕ Café & Página

> Um café para acompanhar cada história.

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Web,
utilizando HTML, CSS, JavaScript e PHP.

---

## 📖 Sobre o projeto

O Café & Página é um site fictício de uma cafeteria e livraria,
criado como projeto acadêmico para a disciplina de Desenvolvimento Web.

A proposta é desenvolver o projeto progressivamente conforme os
conteúdos da disciplina forem apresentados, iniciando com HTML e CSS
e posteriormente incorporando JavaScript e PHP.

---

## 🎯 Objetivo

Desenvolver um site funcional e responsivo, aplicando na prática
os conceitos apresentados durante a disciplina.

O projeto também tem como objetivo proporcionar experiência de
trabalho colaborativo utilizando Git e GitHub.

---

## 📌 Padrão de commits

Para manter o histórico do projeto organizado e facilitar o acompanhamento
do desenvolvimento, os commits devem seguir um padrão de identificação.

### Tipos de commit

| Tipo | Utilização |
|---|---|
| `feat` | Adição de uma nova funcionalidade ou conteúdo |
| `fix` | Correção de erros |
| `docs` | Alterações na documentação |

### Exemplos

```bash
git commit -m "feat: cria estrutura inicial da página home"
git commit -m "feat: adiciona seção de livros em destaque"
git commit -m "fix: corrige links do menu"
git commit -m "docs: atualiza README"

```
## 🌿 Fluxo de desenvolvimento

Cada integrante deverá desenvolver suas alterações em uma branch própria,
evitando alterações diretamente na branch `main`.

### Estrutura

- `main` — versão principal e estável do projeto
- `feat/nome-da-pagina` — desenvolvimento de novas páginas ou funcionalidades
- `fix/nome-do-problema` — correção de problemas

### Exemplo

```text
main
 │
 ├── feat/home
 ├── feat/cardapio
 ├── feat/livros
 ├── feat/sobre
 └── feat/contato
 ```
